# Human Face Detection using CNN and Flask

A simple and professional AI-based Human Face Detection web application built using Python, Flask, OpenCV, and Deep Learning concepts.

The system allows users to upload images and detects human faces using a pre-trained deep learning face detection model.

---

# 🚀 Features

- Upload any image for face detection
- Detect human faces using deep learning model
- Draw bounding boxes around detected faces
- Display number of faces detected
- Clean and modern web UI
- Flask-based web application
- Fast and lightweight project

---

# 🛠️ Technologies Used

- Python
- Flask
- OpenCV
- NumPy
- HTML
- CSS
- Deep Learning (Pre-trained CNN model)

```bash

pip install -r requirements.txt

python app.py

## Step 4 — Open in Browser

🧠 How It Works
User uploads an image
Image is processed using OpenCV
Deep learning-based face detection is applied
Bounding boxes are drawn on detected faces
Result is displayed on web page
